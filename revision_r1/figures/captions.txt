WorkCert exchange workflow. The producer selects nodes and evaluates reconstruction errors against the full numerical reference. The consumer validates the exchanged file, applies an explicit application-level tolerance policy and evaluates reusable queries without that reference. Unmet branch budgets or unresolved comparisons request source-side refinement. OpenAI Codex assisted with the archived figure code.

fig05_exchange_scale
Exchange measurements and numerical cost. (a) Actual uncompressed JSON sizes for 70 references; reduced and full-node WorkCert files include their error, identity and checksum metadata, whereas minimal dense JSON contains coordinates, units and source identity only. Points show individual references; boxes show medians and interquartile ranges with 1.5-IQR whiskers. (b) Median and interquartile range across reference-specific timings; loads include file validation and cache construction, and each query batch contains 10,000 locations. Loading and ordinary queries use three independent processes with five measurements after warm-up per process. No fallback occurred at the 1.4 million tested query locations per representation. (c) A synthetic signed stress fixture uses three measurements after warm-up per process and triggers fallback for every query; the diagnostic bypass is faster but loses the small integral. Bars show minimum and maximum process medians. (d) Previously archived three-process construction timings for one million synthetic samples under the same interval-error target; symbols show individual processes. OpenAI Codex assisted with the archived plotting code.
